## Ответы

1. Зачем выносить виджеты в отдельные файлы?
- Улучшает читаемость, упрощает поддержку и позволяет переиспользовать код. Если всё держать в main.dart, файл быстро станет огромным, запутанным и сложным для редактирования.

2. Что такое BuildContext?
- Это объект, который хранит информацию о положении виджета в дереве Flutter. Он передаётся в build(), чтобы виджет мог обращаться к окружению (темам, навигации, родительским виджетам) и корректно отрисовываться.

3. Чем StatelessWidget отличается от StatefulWidget?
- StatelessWidget не меняет своё состояние после создания (статичный UI: текст, иконки, фон). StatefulWidget хранит изменяемые данные и перерисовывается при вызове setState() (интерактивные элементы: счётчик, кнопка, игра с кубиком).

4. Почему Random() создаётся на уровне файла, а не внутри rollDice()?
- Один глобальный объект экономит память и процессорное время. Если создавать Random() внутри метода, при быстрых нажатиях генератор может выдавать одинаковые числа (из-за привязки seed к системному времени). Глобальный экземпляр гарантирует стабильную случайность.
